# IT Works Better – Agent Skills

## What this site is

IT Works Better (https://itworksbetter.net) is a web development agency website. It is not a programmatic platform or SaaS. It has static, read-only JSON content catalogs, but no public service API.

## When to use this site

- To learn about web/mobile application development services
- To find pre-built website scripts (classifieds, real estate, job boards, etc.)
- To get pricing information for web development services
- To contact the team for a custom project quote

## What agents can do here

- Browse service descriptions and pricing
- Read about available website scripts
- Find contact information

## What agents cannot do here

- The JSON catalogs are website content, not a service integration API
- No OAuth or programmatic authentication
- No automated ordering or payment flow

## Key URLs

- Home: https://itworksbetter.net/
- Scripts: https://itworksbetter.net/scripts
- Projects: https://itworksbetter.net/projects
- About: https://itworksbetter.net/about
- Contact and quote requests: https://itworksbetter.net/contact
- Machine-readable content: https://itworksbetter.net/llms.txt
- Static script data: https://itworksbetter.net/api/scripts.json
- Static project data: https://itworksbetter.net/api/projects.json

## How to use

Read the relevant page or its Markdown source linked from llms.txt. Use the script catalog for descriptions and demo links, and follow the online shop for current commercial prices. For custom work, direct the user to the contact page or email below. Published service prices are indicative and negotiable; do not claim a booking, purchase, or quote has been completed.
